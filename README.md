# Поиск бесплатного Wi-Fi в MAX

Бот: https://max.ru/wifipoints_digitalkostroma_bot

## Поиск

Пользователь отправляет геолокацию. Бот возвращает до трёх ближайших точек без ограничения радиуса: название, адрес, расстояние и ссылку на Яндекс.Карты. Расстояние рассчитывается по формуле гаверсинусов. Текст не используется вместо геоточки. При пустом реестре бот сообщает, что точки пока не добавлены.

Реестр содержит 76 точек Ростелекома. Дополнительные точки загружает оператор или администратор. Для импортированных точек SSID и пароли не указаны в источнике. В текущей пользовательской выдаче SSID, пароль и комментарий не выводятся, хотя могут храниться в записи.

## Управление точками и ролями

- Любой пользователь может искать ближайшие точки.
- Оператор и администратор могут добавлять, редактировать, удалять и просматривать точки.
- Администратор дополнительно создаёт приглашения на роли, снимает роли и просматривает их список. Приглашения действуют 15 минут, используются один раз. Один пользователь может иметь несколько ролей.

Добавление через меню требует одну строку из семи полей:

```text
Название; Адрес; Широта; Долгота; SSID; Пароль; Комментарий
```

Название, адрес и SSID обязательны при ручном вводе. Пароль и комментарий могут быть пустыми, разделители сохраняются. Координаты проверяются по диапазонам широты и долготы. Для редактирования и удаления сначала указывается ID из списка; удаление требует подтверждения.

## Массовая загрузка

На сервере `manage.py wifi import-wifi --file /path/points.json` принимает массив:

```json
[
  {"id": "source-001", "name": "Wi-Fi", "address": "Адрес точки",
   "latitude": 57.77, "longitude": 40.93,
   "ssid": "", "password": "", "comment": "Источник реестра"}
]
```

Импорт, в отличие от ручной формы, допускает отсутствие SSID. Записи обновляются по стабильному `id` источника (в БД префикс `import:`); отсутствующие в новом файле записи автоматически не удаляются. Перед импортом нужна согласованная резервная копия SQLite. Для исходного формата Ростелекома есть `tools/prepare_wifi_import.py` и `deploy/import-rtk-wifi.sh` (конвертер читает исходный JSON из текущего рабочего каталога).

## Реализация и запуск

Рабочая версия включена в каталог `src/` этого репозитория. Это общий код трёх приложений; для данного бота укажите `BOT_KIND=wifi`. Каждое приложение запускается отдельным процессом с собственной БД и конфигурацией. Описание переменных окружения, запуска и обслуживания: [запуск и обслуживание](docs/runtime.md).

Стек рабочей версии: Python 3.12 на VDS, aiohttp, Peewee, SQLite. События поступают через HTTPS webhook MAX; входящие события и исходящие сообщения сохраняются в SQLite. Диалоги хранятся в БД, срок состояния — 10 минут. `/start` сбрасывает текущий диалог, `/id` показывает MAX ID, «Отмена» отменяет текущий ввод.

Роли проверяются перед действиями; права выдаются одноразовыми приглашениями либо администратором сервера через `manage.py`. Последнюю роль администратора снять через меню нельзя. Секреты и рабочие БД в Git не сохраняются.

Тесты и пробные обращения в ботов по указанию владельца не запускаются.

## Структура репозитория

- src/ — рабочий Python-код и публичная цепочка сертификатов портала.
- deploy/ — скрипты существующего VDS.
- docs/ — документация эксплуатации.
- requirements.txt — закреплённые зависимости рабочей версии.
- .env.example — шаблон конфигурации без секретов.

Установка: python -m pip install -r requirements.txt. После загрузки настроек в окружение: python -B src/app.py. Файл .env автоматически не загружается. Для 'wifi' используйте BOT_KIND=wifi. Текущие данные хранятся в data/ и не включаются в Git.

## Карта всех точек

Кнопка «Карта всех точек» открывает карту с реестром, поиском по адресу/названию и выбором трёх ближайших по геолокации. В топливной карте можно выбрать марку топлива; дата источника и предупреждения об устаревших сведениях сохраняются. Исходный поиск в диалоге бота также доступен. Карта включается параметром `MAP_ENABLED=1`. Развёртывание описано в [документации](docs/runtime.md#развёртывание).
## Категории на карте Wi-Fi

Фильтр «Категория»: «Все точки», «РТК», «СЗО», «Дополнительные точки». Он применяется одновременно к карте, списку, поиску по адресу и трём ближайшим. Категория показана в карточке точки. Топливных полей на карте Wi-Fi нет.

В импортируемой JSON-записи необязательное поле `category` принимает `rtk`, `szo`, `additional`. При повторном импорте без этого поля уже заданная категория сохраняется. Редактирование через меню также сохраняет категорию. Существующие точки из реестра Ростелекома определяются по стабильному префиксу источника `import:rtk-`; прочие записи без категории относятся к дополнительным. Пустая категория показывает сообщение об отсутствии подходящих точек; данные других категорий не подставляются.

### Карта на телефоне

В вертикальной ориентации карта расположена над списком, поля и кнопки переносятся по ширине экрана. В горизонтальной ориентации карта и прокручиваемый список показаны рядом, шапка компактная. При повороте экрана размеры карты и высота всплывающей карточки пересчитываются автоматически. Фильтры и поиск сохраняются при повороте.
